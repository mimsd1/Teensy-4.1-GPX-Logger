GPX is an open-format XML-based file type designed around storing GPS data in a neat and organized manner. There are three main "data types": Waypoints, Routes and Tracks. 

Waypoints are as they sound, a single GPS location at one given point in time.
Routes are essentially a collection of points, typically used for mapping out ahead of time, however in my script Im using route points to log.
Tracks are a blend of waypoints and routes, typically used to mark a completed/logged trip. This more akin to what the goal of this script is, however for my purposes they work essentially identically.

You can then feed this file into a GPS device that can read GPX files or a website that allows you to map out the recorded data.
